# HR Analytics Dashboard 

This project showcases an interactive HR Analytics Dashboard built using **Tableau** to visualize and analyze employee data.

- `HumanResources.csv` : Sample dataset used (anonymized)

## Dashboard Features
- **Employee Overview**: Active employees, hiring trends, and termination trends.
- **Demographics Analysis**: Gender, age group, education distribution.
- **Income & Performance**: Relationship between salary, education, performance.
- **Location Insights**: Employee count across branches and HQ.
- **Role & Salary Details**: Drill-down employee list with filters.

## Tools Used
- **Tableau** for data visualization
- **Excel / CSV** for data handling
